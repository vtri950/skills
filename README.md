# skills

Claude Code skills collection.

## Available skills

| Skill | Description |
|-------|-------------|
| [visual-docs](./visual-docs/) | Author and convert documentation to rich MDX files viewable locally with [planview](https://github.com/vtri950/planview) |

## How to install a skill

Copy the skill directory into your Claude Code user skills folder:

```bash
cp -r visual-docs ~/.claude/skills/
```

Or reference the skill directory directly in your Claude Code settings.
